# 应用场景教学

## 1. 最小脚本

`build.mk`：

```c
func main() -> void {
    info("hello");
}
```

```bat
ccmake -c project.mc -f build.mk
```

脚本没有必填项。`main` 为空或不存在时正常退出。

## 2. 编译单个项目

`project.mc`：

```text
"output": "build/hello.exe";
"toolchain": {
    "cc": "gcc";
    "cflags": ["-O2", "-Wall"];
};
```

`build.mk`：

```c
@include "project.mc";

func main() -> void {
    list<string> sources = find_files("*.c", {"src"});
    info("cc: %s", @{toolchain.cc});

    mkdir(dirname(@{output}));
    command(
        @{toolchain.cc},
        @{toolchain.cflags} + sources + {"-o", @{output}}
    );
}
```

执行：

```bat
cd examples\hello
..\..\out\windows_amd64_bin\ccmake.exe -c project.mc -f build.mk
```

`command` 直接传 argv，不经过 shell。动作按源码顺序执行。

## 3. 手动增量

```c
func main() -> void {
    list<string> sources = find_files("*.c", {"src"});
    if (!file_exists(@{output}) ||
        file_newer("src/main.c", @{output})) {
        mkdir(dirname(@{output}));
        command(
            @{toolchain.cc},
            @{toolchain.cflags} + sources + {"-o", @{output}}
        );
    }
}
```

`file_exists`、`file_mtime`、`file_newer` 查询文件状态。是否重建由脚本条件决定。

## 4. 运行时生成中间产物

```c
func main() -> void {
    mkdir("build");

    if (!file_exists("build/generated.c")) {
        command("tool", {"--generate", "build/generated.c"});
    }

    command("cc", {"build/generated.c", "-o", "build/app"});
}
```

中间产物不要求在 Configure 阶段存在。

## 5. 目录与工作目录

相对路径按当前工作目录解析。推荐先进入项目目录：

```bat
cd examples\hello
..\..\out\windows_amd64_bin\ccmake.exe -c project.mc -f build.mk
```

`-C <目录>` 设置 CCMake 工作目录；外部命令默认继承启动 `ccmake` 时的进程 cwd，`command` 的 `cwd` 参数可单独指定。

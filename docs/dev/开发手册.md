## 全局变量

命令行解析后，参数值填充到 `ccmaker_global.cmd` 结构体中。访问方式为 `ccmaker_global.cmd.xxx`。

```c
typedef enum {
    CC_CMD_FLAG_ACTION_DONE,  // 已执行动作类参数，后续无需继续
    CC_CMD_FLAG_NEED_BUILD    // 需要执行构建
} CC_CMD_PARSE_STAT;

struct ccmake_global_var_struct {
    char *self_path;
    char *ccm_path;          // -c / --config
    char *cmk_path;          // -f / --file
    char *work_dir;          // -C / --directory
    char *output_dir;        // -o / --output
    char *target;            // -t / --target 或位置参数
    int   jobs;              // -j / --jobs (0 = 自动检测)
    CC_CMD_PARSE_STAT stat;  // 状态枚举，告知后续流程走哪个分支
    CCBOOL  verbose;         // -v / --verbose
    CCBOOL  dry_run;         // -n / --dry-run
    CCBOOL  always_build;    // -B / --always-build
    CCBOOL  keep_going;      // -k / --keep-going
    // -D 定义覆盖可用链表/哈希表存储
};

```

**`stat` 字段说明**：

| 枚举值 | 含义 |
|---|---|
| `CC_CMD_FLAG_ACTION_DONE` | 已执行动作类参数（如 `-V`、`-h`），`main` 应直接 `return 0`，不再执行构建 |
| `CC_CMD_FLAG_NEED_BUILD` | 需要继续执行构建操作（指定了 `-f` 且无动作类参数），`main` 应继续构建流程 |

# 架构说明

## 模块职责

| 模块 | 职责 |
|---|---|
| `ccm` | `.ccm` 定位、扫描、解析与配置树 |
| `cmk_lexer` | 源码到 token |
| `cmk_parser` | token 到 AST |
| `cmk_semantic` | 作用域、类型、函数与内建绑定 |
| `cmk_runtime` | 全局变量初始化、函数调用、表达式与控制流 |
| `cmk_builtin` | 内建函数注册与调用 |
| `cmk_executor` | 进程与文件动作执行 |
| `cmk_program` | 模块加载、导入、Configure 与 `main` 入口 |
| `cmk_process` | 平台进程创建、等待与输出捕获 |

## 执行顺序

```text
命令行解析
  → CCM 定位与解析
  → CMK 词法
  → CMK 语法
  → Semantic
  → 模块全局变量初始化
  → 调用 main()
  → 动作函数直接执行
```

`main` 固定为：

```c
func main() -> void
```

没有 `main` 时直接成功退出。`main` 有参数或返回非 `void` 时在执行前报错。

## 作用域与导入

- 模块级变量、函数、导入函数进入模块作用域；
- 函数参数与局部变量进入函数作用域；
- 块、`for-in` 建立独立作用域；
- `@import func` 只导入函数；
- 模块级变量不跨模块导出。

## 全局变量初始化

`cmk_program_configure` 按模块顺序初始化全局变量。全局变量初始化表达式可以调用普通函数；普通函数中的动作函数立即执行。副作用顺序与初始化顺序一致。

## 动作

```c
mkdir(path);
copy(from, to);
move(from, to);
remove(path);
command(program, args);
command(program, args, cwd);
command(program, args, cwd, env);
```

这些函数返回 `void`，调用即执行：

- 文件动作直接操作文件系统；
- `command` 创建进程并等待；
- 失败立即终止当前脚本；
- 进程输出写入 stdout；
- 参数直接传 argv，不经过 shell。

## 资源所有权

- AST、语义记录与运行时由 `CMKProgram` 持有；
- 模块全局变量由对应 `CMKRuntime` 持有；
- 函数返回值由调用方清理；
- 动作参数列表由表达式值持有，执行期间有效；
- `CMKExecutor` 与 `CMKProcess` 在动作结束后释放。
